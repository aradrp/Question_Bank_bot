# 🤖 ربات بانک سوالات کنکور

ربات تلگرامی برای دسترسی سریع و آسان به بانک سوالات کنکور — مناسب دانش‌آموزانی که می‌خوان برای کنکور تمرین کنن، بدون نیاز به نصب اپلیکیشن یا مراجعه به سایت جداگانه.

## ✨ ویژگی‌ها

- 📚 دسترسی به بانک سوالات دسته‌بندی‌شده بر اساس درس و مبحث
- 🎯 حالت تمرین برای آماده‌سازی کنکور
- 🔀 نمایش تصادفی سوالات
- 💬 رابط کاربری ساده و کاملاً مبتنی بر چت تلگرام
- ⚡ سبک، سریع و بدون نیاز به نصب اضافی

## 🚀 شروع سریع

### پیش‌نیازها

- Python 3
- یک توکن ربات تلگرام (از [@BotFather](https://t.me/BotFather) بگیر)

### نصب

```bash
git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME
pip install -r requirements.txt
```

### تنظیمات

توکن ربات رو در یک فایل `.env` قرار بده:

```
BOT_TOKEN=your_telegram_bot_token_here
```

### اجرا

```bash
python bot.py
```

## 📖 نحوه استفاده

1. ربات رو در تلگرام پیدا کن: [@YourBotUsername](https://t.me/YourBotUsername)
2. دستور `/start` رو بزن
3. درس یا مبحث موردنظرت رو انتخاب کن
4. شروع کن به تمرین سوالات!

## 🗂 ساختار پروژه

```
├── bot.py               # فایل اصلی اجرای ربات
├── questions/           # بانک سوالات (بر اساس درس دسته‌بندی شده)
├── handlers/            # هندلرهای مربوط به دستورات و پیام‌ها
├── requirements.txt      # وابستگی‌های پروژه
└── README.md
```
